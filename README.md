# 🛫 Airport Dataset (IATA + COUNTRY + NAME + ....) (English + Persian)

An open-source JSON dataset of international airports, including IATA codes, country and city names, and full airport names in both English and Persian (Farsi).

## 📌 Features

- IATA code
- Persian/English city & country & name
- Country code (ISO 3166-1 alpha-2)
- Flags for domestic airports (`is_dom`) and favorites (`is_fav`)

This dataset is ideal for travel apps, flight search engines, or any multilingual application dealing with airport data.

## 🌍 Supported Locales

- English
- فارسی (Farsi)

---

## 🇮🇷 دیتاست فرودگاه‌ها (انگلیسی + فارسی)

یک دیتاست JSON متن‌باز از فرودگاه‌های بین‌المللی با اطلاعاتی نظیر کد IATA، نام کشور و شهر به زبان‌های فارسی و انگلیسی و همچنین نام فرودگاه به دو زبان.

### 📌 ویژگی‌ها

- کد IATA
- نام کشور و شهر به زبان انگلیسی و فارسی
- نام فرودگاه به زبان فارسی و انگلیسی
- کد کشور (بر اساس استاندارد ISO 3166-1 alpha-2)
- فیلدهای `is_dom` (پرواز داخلی بودن) و `is_fav` (مورد علاقه بودن)

این دیتاست برای اپلیکیشن‌های گردشگری، موتورهای جست‌وجوی پرواز و هر پروژه چندزبانه‌ای کاربردی است.

## 📂 Usage

Clone or download the repository and load the JSON file into your project:

```bash
git clone https://github.com/rezkhaleghi/airport-iata-fa.git
```

## 🤝Contributing

This dataset is a work in progress. Some airport records currently lack English fields for city and name and only contain information in Persian (Farsi).
We welcome contributions to help:

- Add missing English city and airport names

- Fix or update incorrect entries

- Add new airports or improve existing ones

- Refactor the structure if needed

Feel free to open an issue or submit a pull request! Every bit helps improve this open dataset.

---

این دیتاست هنوز کامل نیست. برخی از رکوردهای فرودگاه‌ها فاقد نام انگلیسی شهر و فرودگاه هستند و فقط اطلاعات فارسی دارند.
از مشارکت‌های شما برای بهبود دیتاست استقبال می‌کنیم، از جمله:

- افزودن نام انگلیسی شهر و فرودگاه برای رکوردهای ناقص
- اصلاح یا به‌روزرسانی داده‌های نادرست
- افزودن فرودگاه‌های جدید یا بهبود فرودگاه‌های موجود
- بازسازی ساختار در صورت نیاز
